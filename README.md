# 🥤 Refrigerantes de Frutas

Uma experiência visual interativa para apresentação de uma linha fictícia de refrigerantes, desenvolvida com **HTML, CSS e JavaScript**.

O projeto explora composição visual, identidade de produto e transições entre diferentes sabores através de uma interface inspirada em páginas promocionais de bebidas.

## 🔗 Demonstração

[Acessar o projeto](https://refrigerantes-swart.vercel.app/)

## 🍓 Sobre o projeto

**Refrigerantes de Frutas** apresenta uma coleção conceitual de bebidas com identidades próprias para cada sabor.

Atualmente, a aplicação possui três opções:

* 🍓 **Morango**
* 🥑 **Abacate**
* 🍊 **Laranja**

Cada produto possui sua própria lata, elementos visuais relacionados à fruta e uma composição pensada para destacar o sabor selecionado.

Os controles laterais permitem navegar entre os diferentes produtos da coleção.

## 🎨 Conceito visual

A proposta do projeto vai além de simplesmente trocar imagens.

Cada sabor foi construído como uma pequena identidade de produto, combinando:

* Cor predominante relacionada à fruta;
* Mockup personalizado da lata;
* Imagens decorativas em primeiro plano;
* Tipografia aplicada à embalagem;
* Composição centralizada;
* Elementos sobrepostos para criar profundidade.

As imagens utilizam fundo transparente, permitindo integrar as frutas e embalagens diretamente ao layout.

## ✨ Interação

A interface possui navegação através dos botões **anterior** e **próximo**, permitindo percorrer os sabores disponíveis.

A troca de produto altera o conteúdo apresentado na tela, criando uma experiência semelhante a um **slider de produtos** utilizado em landing pages e campanhas promocionais.

## 🛠️ Tecnologias

* **HTML5** — estrutura da interface;
* **CSS3** — composição visual, posicionamento e estilização;
* **JavaScript** — controle da navegação entre os produtos;
* **Vercel** — deploy da aplicação.

## 🧠 Conceitos praticados

O desenvolvimento deste projeto permitiu trabalhar conceitos como:

* Manipulação de elementos da interface;
* Eventos de interação;
* Controle de estado através de índice;
* Navegação entre elementos;
* Posicionamento de elementos;
* Sobreposição de imagens;
* `z-index`;
* Imagens PNG com transparência;
* Organização de assets;
* Composição visual com CSS;
* Construção de interfaces voltadas à apresentação de produtos.

## 🖼️ Produtos

### 🍓 Morango

Uma identidade baseada em tons avermelhados e rosados, acompanhada por elementos visuais de morango.

### 🥑 Abacate

Versão com identidade esverdeada e elementos inspirados no abacate.

### 🍊 Laranja

Composição baseada em tons alaranjados e dourados, acompanhada por elementos visuais da fruta.
