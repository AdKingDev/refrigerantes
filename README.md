# Refrigerantes de Frutas
Este projeto é um slider interativo de refrigerantes de frutas, desenvolvido com o objetivo de praticar manipulação do DOM, uso de variáveis CSS dinâmicas e criação de interfaces visuais modernas utilizando apenas HTML, CSS e JavaScript puro.

Funcionalidades:
• Navegação entre slides
• Loop infinito (não trava no primeiro nem no último)
• Alteração dinâmica de cores
• Layout centralizado
• Footer adaptável ao slide ativo
• Interface leve sem bibliotecas externas

Link do projeto: https://refrigerantes-swart.vercel.app/
